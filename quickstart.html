Step 1 — Watch it run

One click. No install. No signup.

This runs a real agent against the live API: it opens a session with a budget, checks what the agent may and may not do, stores a secret, authorizes a payment, writes to the audit trail, verifies the hash chain, then revokes the session — and shows the agent being locked out.

Step 3 — Point your own agent at it

One URL. That's the whole setup.

Haldir is an MCP server. Any MCP client that accepts a remote server URL can use it — paste this, add your key as a bearer token, and your agent's tool calls start being checked, logged, and capped.

https://haldir.xyz/mcp

19 tools: sessions, permissions, secrets, payments, approvals, the audit trail, and the Merkle proofs behind it.

What just happened

Your agent was governed.

Every action was scoped to a session with permissions and a spend limit. The secret was AES-256-GCM encrypted. The payment was authorized against the session budget. Every action was logged to a hash-chained, tamper-evident audit trail. And when you revoked the session, the agent lost all access instantly.
